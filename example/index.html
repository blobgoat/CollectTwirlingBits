Hero Text Avoidance Test

Twirling Bits ✦

Hover over the golden stars to collect them. They spawn randomly on the screen and should avoid overlapping visible text. Use the debug panel above to start, stop, and reset the experience.

Card Layout Test

Cards with Text

Spawn Rate

One new bit appears every second by default. Adjust spawnEveryMs to change the rate.

Max On Screen

Up to 10 bits can exist at once. Controlled by maxOnScreen.

Star Size

Each bit is 28 px wide. Set via starSize in the options object.

Persistence

Your total is stored in localStorage so it survives page reloads.

Text Avoidance

Bits use a TreeWalker to find text nodes and avoid placing stars on them.

Collection

Hover a bit to collect it. It animates toward the counter at the bottom of the screen.
